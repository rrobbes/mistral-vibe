🔗 Intégration des Hooks

Découvrez comment intégrer les hooks de Mistral Vibe avec vos outils existants, vos workflows et vos systèmes internes. Cette page vous montre comment connecter Mistral Vibe à votre écosystème technique.

📋 Introduction à l'Intégration

🎯 Pourquoi Intégrer les Hooks ?

Les hooks ne sont pas seulement un mécanisme d'extension, ce sont aussi des points de connexion entre Mistral Vibe et votre environnement technique. Voici pourquoi l'intégration est cruciale :

🔗

Connecter vos Outils

Reliez Mistral Vibe à vos systèmes internes : Slack, GitHub, CI/CD, bases de données, APIs.

📊

Centraliser la Gestion

Intégrez les actions de l'IA dans vos systèmes de monitoring, logging et audit existants.

⚡

Automatiser les Workflows

Déclenchez automatiquement des actions externes en réponse aux événements de l'agent.

🛡️

Appliquer vos Politiques

Faites respecter vos règles de sécurité, de conformité et de qualité à travers les hooks.

ℹ️ Point clé : L'intégration via hooks permet une séparation claire entre Mistral Vibe et vos systèmes. Vous gardez le contrôle total tout en bénéficiant des capacités de l'IA.

🏗️ Principes d'Intégration

Pour une intégration réussie, suivez ces principes fondamentaux :

  1. Découplage : Vos hooks doivent être des processus indépendants qui communiquent via JSON.
  2. Idempotence : Un hook doit pouvoir être exécuté plusieurs fois sans effet de bord.
  3. Résilience : Un hook ne doit pas bloquer l'agent en cas d'erreur (sauf si strict=true).
  4. Performance : Optimisez vos hooks pour qu'ils s'exécutent rapidement.
  5. Sécurité : Ne exposez pas de données sensibles dans les logs ou les réponses.

✨ Les 6 Cas d'Usage d'Intégration

Les hooks vous permettent d'implémenter des stratégies transverses qui s'appliquent systématiquement à toutes vos interactions avec l'agent.

🔒

1️⃣ Sécurité & Contrôle d'Accès

Intégration avec : Systèmes de sécurité, politiques internes, lists noires.

Exemple : Hooks PRE_TOOL qui valident les appels avant exécution.

hook_pre_tool_security.py 
#!/usr/bin/env python3
import json
import sys

invocation = json.load(sys.stdin)

if invocation.get("tool_name") == "bash":
    command = invocation.get("tool_input", {}).get("command", "")
    dangerous_commands = ["rm -rf", "chmod -R", ":(){ :|:& };:"]
    if any(dangerous in command for dangerous in dangerous_commands):
        print(json.dumps({
            "decision": "deny",
            "reason": f"Commande dangereuse détectée : {command[:50]}"
        }))
        sys.exit(0)

print(json.dumps({"decision": "allow"}))
sys.exit(0)
🔄

2️⃣ Transformation des Données

Intégration avec : Systèmes de traitement, pipelines ETL, formateurs de données.

Exemple : Hooks PRE_TOOL pour modifier les inputs, POST_TOOL pour modifier les outputs.

hook_post_tool_timestamp.py 
#!/usr/bin/env python3
import json
import sys
from datetime import datetime

invocation = json.load(sys.stdin)
output = invocation.get("tool_output_text", "")
timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

print(json.dumps({
    "decision": "allow",
    "hook_specific_output": {
        "additional_context": f"\n---\n[Generé le {timestamp}]"
    }
}))
sys.exit(0)
📊

3️⃣ Audit & Journalisation

Intégration avec : SIEM, ELK Stack, Datadog, Splunk, fichiers logs.

Exemple : Hooks POST_TOOL et POST_AGENT qui journalisent dans un fichier ou une base.

hook_post_agent_audit.py 
#!/usr/bin/env python3
import json
import sys
from pathlib import Path

invocation = json.load(sys.stdin)

log_file = Path("~/vibe_audit.log")
log_entry = {
    "timestamp": invocation.get("timestamp"),
    "session_id": invocation.get("session_id"),
    "event": "agent_turn_completed"
}

log_file.write_text(json.dumps(log_entry) + "\n", append=True)

print(json.dumps({"decision": "allow"}))
sys.exit(0)
🔗

4️⃣ Intégration Externe

Intégration avec : Slack, Discord, Microsoft Teams, Email, Webhooks.

Exemple : Hooks POST_AGENT qui déclenchent des actions externes.

hook_post_agent_slack.py 
#!/usr/bin/env python3
import json
import sys
import requests

invocation = json.load(sys.stdin)

webhook_url = "https://hooks.slack.com/services/YOUR/WEBHOOK"
message = {
    "text": f"✅ Tâche terminée dans Mistral Vibe (Session: {invocation.get('session_id')})"
}

try:
    requests.post(webhook_url, json=message)
except:
    pass

print(json.dumps({"decision": "allow"}))
sys.exit(0)
🧠

5️⃣ Enrichissement du Contexte

Intégration avec : Bases de connaissances, systèmes de contexte, gestionnaires d'état.

Exemple : Hooks POST_AGENT qui injectent du contexte.

hook_post_agent_context.py 
#!/usr/bin/env python3
import json
import sys
from datetime import datetime
import socket

invocation = json.load(sys.stdin)

context = f"""
Contexte système :
- Date: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}
- Machine: {socket.gethostname()}
- Utilisateur: {invocation.get('session_id', 'unknown')}
"""

print(json.dumps({
    "decision": "allow",
    "system_message": context
}))
sys.exit(0)
✅

6️⃣ Validation & Qualité

Intégration avec : Systèmes de validation, linters, vérificateurs de qualité.

Exemple : Hooks PRE_TOOL qui valident les paramètres avant exécution.

hook_pre_tool_validation.py 
#!/usr/bin/env python3
import json
import sys
import re

invocation = json.load(sys.stdin)

if invocation.get("tool_name") == "write_file":
    content = invocation.get("tool_input", {}).get("content", "")
    if not content.endswith("\n"):
        print(json.dumps({
            "decision": "deny",
            "reason": "Le contenu du fichier doit se terminer par un saut de ligne"
        }))
        sys.exit(0)

print(json.dumps({"decision": "allow"}))
sys.exit(0)

🎯 Scénarios d'Intégration Concrets

Voici des scénarios réels où les hooks apportent une valeur ajoutée immense en termes d'intégration :

🏢 Entreprise - Sécurité Renforcée

🔒 Protection contre les commandes dangereuses

Contexte : Votre entreprise utilise Mistral Vibe en production avec accès à des outils système.

Intégration : Hook PRE_TOOL connecté à votre système de règles de sécurité interne.

Solution : Un hook PRE_TOOL qui vérifie toutes les commandes bash avant exécution et bloque celles qui sont sur une liste noire définie par votre équipe sécurité.

✅ Résultat : Votre environnement est protégé. Toutes les commandes dangereuses sont bloquées avant exécution, avec un message clair expliquant pourquoi. L'intégration avec votre SIEM permet un suivi centralisé.

📜 Juridique - Conformité RGPD

📜 Audit et conformité

Contexte : Vous travaillez dans un secteur réglementé (santé, finance, etc.) et devez respecter le RGPD ou d'autres réglementations.

Intégration : Hook POST_AGENT connecté à votre système de conformité.

Solution : Un hook POST_AGENT qui journalise toutes les conversations dans un système centralisé avec horodatage, session ID, et métadonnées complètes, puis envoie ces données à votre outil de conformité.

✅ Résultat : Vous avez un audit complet de toutes les interactions, prêt pour les vérifications de conformité. Vous pouvez prouver que l'IA n'a pas eu accès à des données sensibles. L'intégration avec votre outil de conformité permet des rapports automatisés.

🚀 DevOps - Automatisation CI/CD

🤖 Intégration CI/CD

Contexte : Votre équipe utilise Mistral Vibe pour générer du code ou de la documentation.

Intégration : Hook POST_TOOL connecté à votre pipeline Jenkins/GitHub Actions.

Solution : Un hook POST_TOOL qui déclenche votre pipeline CI/CD après que Mistral Vibe ait généré du code via write_file.

✅ Résultat : Votre workflow DevOps est entièrement automatisé : code généré → tests → déploiement. Plus besoin d'intervention manuelle. L'intégration avec votre pipeline CI/CD garantit que chaque modification est testée.

📁 Multi-Projets - Configuration Spécifique

📁 Règles par projet

Contexte : Vous travaillez sur plusieurs projets avec des règles différentes. Certains projets autorisent l'accès à des outils sensibles, d'autres non.

Intégration : Hooks configurés par projet avec des fichiers TOML spécifiques.

Solution : Des fichiers de configuration TOML différents par projet qui définissent quels hooks s'appliquent. Les hooks peuvent lire le contexte du projet actuel depuis votre système de gestion de projets.

✅ Résultat : Chaque projet a ses propres règles de sécurité et de comportement, sans conflit. Le passage d'un projet à l'autre est transparent. L'intégration avec votre système de gestion de projets permet une configuration centralisée.

💡 Productivité - Enrichissement Intelligent

💡 Contexte automatique

Contexte : Vous utilisez Mistral Vibe quotidiennement pour diverses tâches.

Intégration : Hook POST_AGENT connecté à votre système d'information.

Solution : Un hook POST_AGENT qui injecte automatiquement des informations contextuelles (date, heure, version du projet, utilisateur connecté, etc.) depuis votre annuaire LDAP ou votre système de gestion d'identité.

✅ Résultat : L'IA connaît toujours le contexte de votre environnement, ce qui améliore la pertinence des réponses et réduit la friction. L'intégration avec votre système d'information garantit que les données sont toujours à jour.

🛠️ Intégration avec des Outils Spécifiques

💬 Intégration avec Slack

Notifiez votre équipe des actions importantes de Mistral Vibe.

Hook à utiliser : POST_AGENT ou POST_TOOL

Exemple d'utilisation :

  • Notifier quand une tâche complexe est terminée
  • Envoyer des alertes pour les erreurs
  • Partager les résultats importants
Configuration Slack 
[[hooks]]
name = "slack-notify-completion"
type = "post_agent"
command = "python3 ~/.vibe/hooks/integration/slack_notify.py"
timeout = 10
strict = false
description = "Notifie Slack quand une tâche est terminée"

# Dans votre hook Python :
import os
webhook_url = os.getenv("SLACK_WEBHOOK_URL")
requests.post(webhook_url, json={"text": "Tâche Mistral Vibe terminée !"})

📊 Intégration avec des Systèmes de Monitoring

Suivez l'utilisation de Mistral Vibe dans vos outils de monitoring.

Hook à utiliser : POST_TOOL ou POST_AGENT

Outils compatibles : Prometheus, Datadog, New Relic, ELK Stack

Exemple avec Prometheus 
#!/usr/bin/env python3
import json
import sys
from prometheus_client import Counter, start_http_server

# Créer un compteur Prometheus
HOOK_EXECUTIONS = Counter('vibe_hook_executions_total', 
                          'Nombre total d_exécutions de hooks', 
                          ['hook_name', 'type', 'status'])

def main():
    try:
        invocation = json.load(sys.stdin)
        hook_name = invocation.get("hook_name", "unknown")
        hook_type = invocation.get("hook_event_name", "unknown")
        
        # Incrémenter le compteur
        HOOK_EXECUTIONS.labels(hook_name, hook_type, "success").inc()
        
        print(json.dumps({"decision": "allow"}))
        sys.exit(0)
    except:
        HOOK_EXECUTIONS.labels(hook_name, hook_type, "error").inc()
        print(json.dumps({"decision": "allow"}))
        sys.exit(1)

# Dans un autre processus : start_http_server(8000)

🔄 Intégration avec CI/CD

Déclenchez automatiquement des pipelines de test et de déploiement.

Hook à utiliser : POST_TOOL (sur write_file)

Outils compatibles : Jenkins, GitHub Actions, GitLab CI, CircleCI

Exemple avec GitHub Actions 
#!/usr/bin/env python3
import json
import sys
import subprocess

invocation = json.load(sys.stdin)

# Déclencher un workflow GitHub Actions
if invocation.get("tool_name") == "write_file":
    path = invocation.get("tool_input", {}).get("path", "")
    if path.endswith(".py"):
        # Déclencher le workflow
        subprocess.Popen([
            "gh", "workflow", "run", "tests.yml",
            "--repo", "mon-org/mon-repo"
        ])

print(json.dumps({"decision": "allow"}))
sys.exit(0)

📁 Intégration avec des Bases de Données

Stockez les résultats et les métadonnées dans une base de données.

Hook à utiliser : POST_TOOL ou POST_AGENT

Bases de données compatibles : PostgreSQL, MySQL, MongoDB, SQLite

Exemple avec PostgreSQL 
#!/usr/bin/env python3
import json
import sys
import psycopg2

invocation = json.load(sys.stdin)

# Connexion à la base de données
conn = psycopg2.connect(
    host="localhost",
    database="vibe_metrics",
    user="vibe",
    password="password"
)

try:
    with conn.cursor() as cur:
        cur.execute("""
            INSERT INTO hook_executions 
            (timestamp, session_id, tool_name, status, duration_ms)
            VALUES (%s, %s, %s, %s, %s)
        """, (
            invocation.get("timestamp"),
            invocation.get("session_id"),
            invocation.get("tool_name"),
            invocation.get("tool_status"),
            invocation.get("duration_ms")
        ))
        conn.commit()
finally:
    conn.close()

print(json.dumps({"decision": "allow"}))
sys.exit(0)

🌟 Bonnes Pratiques d'Intégration

✅

Utilisez des Variables d'Environnement

Ne codez pas les informations sensibles (tokens, URLs, mots de passe) directement dans vos hooks.

Exemple 
# ❌ À éviter
webhook_url = "https://hooks.slack.com/services/MON/WEBHOOK"

# ✅ À faire
import os
webhook_url = os.getenv("SLACK_WEBHOOK_URL")
🔒

Gérez les Erreurs Gracefully

Un hook ne doit pas bloquer l'agent en cas d'erreur d'intégration.

Exemple 
try:
    requests.post(webhook_url, json=message, timeout=5)
except Exception as e:
    # Loguer l'erreur mais ne pas bloquer l'agent
    sys.stderr.write(f"Erreur Slack: {e}\n")
    pass
⚡

Optimisez les Timeouts

Définissez des timeouts appropriés pour les appels réseau.

Exemple 
# ✅ Bon timeout pour un webhook
requests.post(webhook_url, timeout=5)

# ✅ Dans le TOML
[[hooks]]
name = "slack-notify"
type = "post_agent"
command = "python3 hooks/slack.py"
timeout = 10  # Donne 5s de marge
📊

Utilisez le Matching

Appliquez vos hooks d'intégration uniquement aux outils pertinents.

Exemple 
# ✅ Seulement pour write_file
[[hooks]]
name = "trigger-ci"
type = "post_tool"
command = "python3 hooks/trigger_ci.py"
match = "write_file"
timeout = 15

# ✅ Pour plusieurs outils
match = "write_file,edit_file,create_file"
🔄

Cachez les Résultats

Évitez les appels répétitifs aux mêmes APIs externes.

Exemple 
import functools
import requests

@functools.lru_cache(maxsize=100)
def get_user_info(user_id):
    response = requests.get(f"https://api.example.com/users/{user_id}")
    return response.json()
📝

Documentez vos Hooks

Ajoutez des descriptions claires dans votre configuration TOML.

Exemple 
[[hooks]]
name = "slack-notify-completion"
type = "post_agent"
command = "python3 hooks/slack_notify.py"
timeout = 10
strict = false
description = "Envoie une notification à Slack #vibe-alerts quand une tâche est terminée. Utilise SLACK_WEBHOOK_URL."
