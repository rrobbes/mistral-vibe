# Subagents Documentation

This directory contains documentation about the subagent system in Mistral Vibe.

## Contents

- **[subagents.md](./subagents.md)** - Comprehensive guide to subagents in Mistral Vibe

## Overview

The subagent system enables Mistral Vibe to delegate tasks to specialized agents that run independently. This allows for:

- Parallel work streams
- Specialized task execution
- Context isolation
- Improved efficiency
