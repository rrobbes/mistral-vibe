6 Modules Principaux

Les 6 modules essentiels qui composent le cœur du système de sessions

SessionLogger

Enregistre en temps réel les messages et métadonnées de vos sessions actives, avec sauvegarde atomique pour éviter toute corruption.

  • Écriture atomique via fichiers temporaires
  • Validation des données avant sauvegarde
  • Gestion des erreurs intégrée
  • Horodatage précis de chaque message

SessionLoader

Charge vos sessions existantes depuis le disque avec vérification d'intégrité complète pour garantir que vos données ne sont pas corrompues.

  • Désérialisation JSON sécurisée
  • Vérification d'intégrité systématique
  • Reconstruction complète du contexte
  • Gestion des versions compatibles

SessionIndex

Index centralisé et optimisé de toutes vos sessions pour un accès rapide et efficace, même avec des centaines de sessions.

  • Indexation automatique des nouvelles sessions
  • Recherche rapide par ID, titre ou date
  • Mise à jour incrémentale intelligente
  • Cache optimisé pour les performances

LastSessionPointer

Pointeur intelligent qui mémorise automatiquement votre dernière session par terminal (TTY) pour une reprise transparente.

  • Gestion par terminal (TTY) distinct
  • Persistance entre les redémarrages
  • Reprise automatique et transparente
  • Compatible avec les multi-onglets

ResumeSessions

Interface principale qui permet de lister et de reprendre vos sessions précédemment sauvegardées avec une intégration CLI complète.

  • Liste complète des sessions disponibles
  • Reprise par ID ou par titre
  • Intégration native avec le CLI Vibe
  • Filtrage intelligent des sessions

SavedSessions

Gère vos sessions sauvegardées avec des outils d'organisation avancés pour garder vos conversations bien structurées.

  • Épinglage des sessions importantes
  • Renommage personnalisé des sessions
  • Suppression sécurisée des sessions
  • Tri automatique par date ou par nom

Le système contient 16 modules au total, mais ces 6 modules sont les principaux pour l'expérience utilisateur.

Fonctionnalités Clés

Découvrez comment le système de sessions améliore votre expérience avec Mistral Vibe

1

Reprise Automatique et Transparente

Le système détecte automatiquement votre dernier terminal (TTY) utilisé et charge la session correspondante. Vous reprenez exactement où vous vous êtes arrêté, sans aucune action manuelle. Même après avoir fermé votre terminal ou redémarré votre machine, votre conversation est là, prête à continuer.

Zéro effort - tout est automatique
2

Fork & Rewind - Exploration Libre

Testez plusieurs approches sans perdre votre travail. La commande /fork crée une copie de votre session à un point précis, vous permettant d'explorer un chemin différent. La commande /rewind <n> vous permet de revenir en arrière de n messages pour corriger ou reprendre une idée.

3

Organisation Complète de Vos Sessions

Gérez efficacement toutes vos sessions avec des outils simples mais puissants. Épinglez vos sessions importantes pour un accès rapide, renommez-les pour plus de clarté, ou supprimez celles que vous n'utilisez plus. Le système vous permet de garder vos conversations organisées selon vos préférences.

/pin Épingler
/rename <titre> Renommer
/delete Supprimer
/resume Lister
4

Performance et Robustesse

Le système est conçu pour être à la fois rapide et fiable. Grâce à un cache intelligent et une architecture bien pensée, toutes les opérations sont effectuées de manière quasi-instantanée. Les écritures atomiques garantissent que vos données ne sont jamais corrompues.

Écritures atomiques - Aucune perte de données
Cache optimisé - Temps de réponse minimal
5

Historique Complet et Accessible

Toutes vos conversations sont sauvegardées dans un format structuré. Les fichiers messages.jsonl contiennent l'historique complet au format JSON Lines, tandis que meta.json stocke les métadonnées comme le titre, les timestamps, et l'ID de session.

~/.vibe/sessions/
└── vibe_20241102_153021_abcd1234/
    ├── messages.jsonl  # Historique des messages
    ├── meta.json       # Metadonnees (titre, ID, etc.)
    └── .session_index.json  # Index global des sessions

Architecture & Principes de Conception

Une conception robuste pour garantir fiabilité, performance et portabilité

Atomicité des Opérations

Chaque écriture est effectuée de manière atomique via des fichiers temporaires + rename, garantissant que vos données sont toujours dans un état cohérent.

# Pattern de sauvegarde atomique
1. Ecrire dans fichier .tmp
2. Valider contenu et integrite
3. Renommer atomiquement vers final

Sécurité Thread-Safe

Des verrous asyncio et threading protègent les opérations concurrentes pour éviter toute corruption.

# Protection des operations
async with self._save_lock:
    await self._validate()
    await self._save()

Cache Intelligent

Un mécanisme de cache avec réconciliation automatique réduit les temps d'accès tout en garantissant les données à jour.

# Mecanisme de cache
if session_id in cache:
    return cache[session_id]
else:
    session = load_from_disk(session_id)
    cache[session_id] = session

Intégrité des Données

Validation Pydantic systématique avant chargement pour garantir que chaque session est valide.

# Validation avec Pydantic
class SessionMetadata(BaseModel):
    session_id: str
    title: str | None = None
    start_time: str
    # Validation automatique

Portabilité Multi-OS

Fonctionne parfaitement sur Linux, macOS et Windows grâce à pathlib.

# Chemin multi-plateforme
from pathlib import Path
session_dir = Path.home() / ".vibe/sessions"
# Fonctionne partout

Comment Utiliser les Sessions

Un guide pratique pour tirer le meilleur parti du système de sessions

1

Démarrer une nouvelle conversation

Lancez simplement Vibe CLI. Une nouvelle session est automatiquement créée.

Automatique - Aucune commande requise
2

Voir vos sessions précédentes

Utilisez /resume pour afficher la liste complète de vos sessions sauvegardées avec leur titre, ID et date.

Toutes vos sessions - à portée de main
3

Reprendre une session existante

Avec /resume <id> ou /resume <titre>, reprenez une conversation précédente exactement là où vous l'aviez laissée.

Instantané - Votre contexte est restauré immédiatement
4

Organiser vos sessions

Personnalisez avec /rename <titre> pour donner un nom explicite. Utilisez /pin pour marquer/désépingler.

/rename "Mon Projet"
/pin
5

Explorer des alternatives

Utilisez /fork pour créer une copie de votre session actuelle. Utilisez /rewind <n> pour revenir en arrière de n messages.

/fork
/rewind 5
6

Nettoyer vos sessions

Supprimez les sessions inutiles avec /delete. Attention : cette opération est irréversible.

Suppression définitive - Vérifiez avant
