# Bienvenue

Bienvenue dans la documentation du module **`vibe/core/llm/backend/`** de Mistral Vibe !

Ce module est **le module responsable de la communication avec les modèles de langage** (LLM). Il fournit une abstraction unifiée pour interagir avec différents fournisseurs (Mistral, OpenAI, Anthropic, Vertex AI, etc.) tout en gérant les spécificités de chaque provider.

## Qu'allez-vous apprendre ?

- **L'architecture** du module et ses composants clés
- **Comment créer et utiliser** un backend LLM
- **Les stratégies de résilience** (retry, pacing, timeouts)
- **Comment ajouter** de nouveaux providers
- **Les diagrammes** pour visualiser les flux

## Prérequis

- Connaissances de base en Python (async/await)
- Familiarité avec les API REST
- Notions de LLM (tokens, messages, streaming)
