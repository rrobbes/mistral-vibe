What is a Skill?

A Skill is a set of custom instructions that you can add to Mistral Vibe to teach it how to better assist you with specific tasks or workflows.

Think of Skills as "plugins" or "extensions" for Vibe's brain. Each Skill contains:

  • ✓ Metadata - Name, description, and configuration
  • ✓ Instructions - The actual guidance for the AI
  • ✓ Scope - Global (all projects) or Project-specific
  • ✓ Access Control - Who can invoke it (you or the AI)
my-skill/SKILL.md 
---
name: code-review
description: Load when reviewing pull requests
user-invocable: true
---

# Code Review Guidelines

1. Check for security vulnerabilities
2. Verify all tests pass
3. Ensure code follows PEP 8
4. Look for performance issues
5. Confirm documentation is updated
ℹ

Skills are Markdown files with YAML frontmatter. The YAML defines the metadata, and the Markdown body contains the instructions.

🔗

How to Use Skills

Invoke a Skill Manually

You can explicitly tell Vibe to use a specific Skill by typing its name with a forward slash:

/code-review

Review this pull request for me

This forces Vibe to load that Skill's instructions for the current conversation.

List Available Skills

To see all available Skills, use:

/skills
Vibe CLI
> /code-review
> Loaded skill: code-review
> Review this PR
Code Review mode activated...

Automatic Skill Loading

Vibe can automatically load Skills based on the context of your request. The AI reads the description field of each Skill and decides if it's relevant.

Example:

If you have a Skill with:

description: Load when working with Python Django projects

And you ask:

"How do I set up Django authentication?"

Vibe will automatically load that Skill if it determines it's relevant.

ℹ

Model-only Skills can be auto-loaded by the AI but are hidden from the / menu. Set user-invocable: false in the metadata.

How to Create a Skill

1

Choose a Location

Decide where your Skill should live:

  • Global: ~/.vibe/skills/
    Available in all your projects
  • Project: .vibe/skills/
    Only available in this project
2

Create the Folder & File

Create a folder with your Skill's name and add a SKILL.md file:

mkdir -p ~/.vibe/skills/my-skill
touch ~/.vibe/skills/my-skill/SKILL.md
3

Add Metadata (YAML Frontmatter)

At the top of your SKILL.md, add YAML metadata between ---:

---
name: my-skill
description: Load this skill when helping with data analysis
tags: [python, analysis, pandas]
user-invocable: true
license: MIT
---

# Your instructions go here

Required Fields:

  • name - Unique identifier (lowercase, hyphens, 1-64 chars)
  • description - When to load this Skill (1-1024 chars)

Optional Fields:

  • user-invocable - Can users invoke with /name? (default: true)
  • disable-model-invocation - Prevent AI from auto-loading (default: false)
  • allowed-tools - Pre-approved tools list
  • license - License information
  • compatibility - Environment requirements
  • metadata - Custom key-value pairs
4

Write Your Instructions

Below the frontmatter, write clear instructions in Markdown:

---
name: python-best-practices
description: Load when writing Python code
---

# Python Best Practices

## Code Style
- Always follow PEP 8 guidelines
- Use type hints for all functions
- Limit line length to 88 characters
- Use descriptive variable names

## Testing
- Write unit tests for all new functions
- Use pytest framework
- Aim for >90% code coverage

## Documentation
- Add docstrings to all public functions
- Use Google-style docstrings
- Update README.md for significant changes
5

Reload and Use

After creating your Skill, reload Vibe to pick it up:

/reload

Then you can use it:

/my-skill

Help me with this task

✓

Pro Tip: Skills are hot-reloaded! Edit your SKILL.md file, run /reload, and your changes are live immediately.
